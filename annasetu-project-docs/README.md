# AnnaSetu AI --- Project Documentation v2.0

Six canonical documents: - `prd.md`: product overview, problem,
solution, goals, target users, MVP and acceptance criteria. -
`architecture.md`: technology stack, folder structure, domain model,
workflows, APIs and deployment. - `rules.md`: safety, allocation,
privacy, coding standards and an explicit troubleshooting protocol. -
`design.md`: emotional design principles, brand/logo direction,
premium-but-friendly palette, typography, spacing, components and UX. -
`tasks.md`: phased implementation tasks with exit gates. - `memory.md`:
locked decisions and a session-by-session record of actual progress.

Read all six before coding. These are specifications, not a completed
application.
